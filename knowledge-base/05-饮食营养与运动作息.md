# 05 饮食营养与运动作息

## [KB-05-001] 补铁：经期女性最需要关注的营养素
- 分类：饮食运动
- 适用阶段：全周期
- 关键词：补铁、缺铁、贫血、补血、红肉、菠菜
- 核心要点：
  1. 月经失血使育龄女性成为缺铁的高风险人群，经量多者风险更高。
  2. 中国居民膳食营养素参考摄入量：18–49 岁女性铁推荐摄入量约 18 mg/天（不同版本略有差异）。
  3. 血红素铁（红肉、动物肝脏、动物血、贝类）吸收率高；植物性铁（豆类、深绿叶菜、黑木耳）吸收率较低。
  4. 维生素 C 能促进植物性铁的吸收；浓茶、咖啡会抑制铁吸收。
  5. 红糖、红枣的补铁作用很有限，主要是心理安慰和补充热量。
- 建议做法：
  1. 每周吃 2–3 次红肉或动物肝脏/血（肝脏每次少量即可）。
  2. 吃植物性铁食物时搭配新鲜蔬果（如青椒、猕猴桃、橙子）。
  3. 餐后 1 小时内不喝浓茶和咖啡。
  4. 不建议自行长期服用铁剂，需查血常规和铁蛋白后遵医嘱补充。
- 需要就医的信号：乏力、头晕、心慌、面色苍白、脱发增多、指甲变脆。
- 证据等级：A
- 来源：中国营养学会《中国居民膳食营养素参考摄入量》；WHO 贫血资料

## [KB-05-002] 钙、镁与 Omega-3
- 分类：饮食运动
- 适用阶段：黄体期
- 关键词：补钙、镁、鱼油、Omega-3、坚果、牛奶
- 核心要点：
  1. 钙对经前综合征有一定改善作用（随机对照研究显示可减轻症状）。
  2. 镁、Omega-3 对痛经和经前不适有初步研究支持，但证据有限。
- 建议做法：
  1. 每天 300–500 mL 奶或奶制品，加上豆制品和深绿叶菜补钙。
  2. 坚果、全谷物、深绿叶菜富含镁。
  3. 每周吃 2 次深海鱼（如三文鱼、鲭鱼）补充 Omega-3。
  4. 补充剂按说明书剂量服用，有肾结石史者补钙前咨询医生。
- 需要就医的信号：无特殊
- 证据等级：B
- 来源：Carlini 等 2022 PMDD 综述；NAPS Guideline 2026

## [KB-05-003] 经期饮食宜忌
- 分类：饮食运动
- 适用阶段：行经期
- 关键词：经期吃什么、来月经不能吃什么、冰的、辣的、咖啡、奶茶
- 核心要点：
  1. 现代医学并没有严格的经期禁忌食物，但冰饮、辛辣、酒精、高糖高盐可能加重部分人的不适。
  2. 中医指南建议经期避免寒凉生冷和酸涩食物，少喝浓茶，不吸烟饮酒。
  3. 咖啡因可能加重乳房胀痛和焦虑，酒精会加重脱水和情绪波动。
- 建议做法：
  1. 推荐：温热的汤粥、优质蛋白、新鲜蔬果、全谷物。
  2. 少量：咖啡每天不超过 1 杯，奶茶选少糖和小杯。
  3. 避免：大量冰饮、酒精、过辣、过咸的食物。
  4. 中医推荐药膳：生姜大枣汤（痛经怕冷者适合，经量多者慎用）。
- 需要就医的信号：无特殊
- 证据等级：B（中医部分 C）
- 来源：T/CACM 1112—2023 第 5.2.1 节；NAPS Guideline 2026

## [KB-05-004] 黄体期嘴馋怎么办
- 分类：饮食运动
- 适用阶段：黄体期
- 关键词：嘴馋、想吃甜的、暴食、控制不住、零食
- 核心要点：
  1. 黄体期基础代谢略有升高，加上血清素波动，想吃甜食和碳水是正常的生理现象，不是意志力差。
  2. 血糖大起大落会加重情绪波动和疲劳。
- 建议做法：
  1. 每 3–4 小时吃一次，正餐加入全谷物和蛋白质。
  2. 准备健康零食：坚果、酸奶、水果、黑巧克力（70% 以上）、全麦饼干。
  3. 想吃甜食时允许自己吃一小份，慢慢享受，不要有负罪感。
- 需要就医的信号：频繁暴食后伴催吐、过度节食或强烈的身材焦虑（可能是进食障碍，建议寻求专业帮助）。
- 证据等级：B
- 来源：NAPS Guideline 2026

## [KB-05-005] 不同阶段的运动建议
- 分类：饮食运动
- 适用阶段：全周期
- 关键词：运动计划、健身、跑步、瑜伽、力量训练、减肥
- 核心要点：
  1. 规律运动（每周 150 分钟中等强度有氧加 2 次力量训练）对周期健康、痛经和情绪都有益。
  2. 月经期：低强度为主（散步、拉伸、轻瑜伽、八段锦）。
  3. 卵泡期：精力好，适合提高强度、做力量训练和间歇训练。
  4. 排卵期：可以保持较高强度；备孕者避免过度剧烈运动。
  5. 黄体期：中等强度为主，后半段可以多做瑜伽、普拉提、快走，帮助缓解经前情绪。
- 建议做法：
  1. 运动强度以「能说话但不能唱歌」为中等强度参考。
  2. 不要为了减肥过度运动加节食，否则可能导致月经紊乱甚至停经。
- 需要就医的信号：运动量大加饮食不足后月经停止（相对能量不足综合征）。
- 证据等级：A
- 来源：WHO 身体活动指南 2020；Armour 等 2019；T/CACM 1112—2023 第 4.3.4、7.2.3 节

## [KB-05-006] 作息与睡眠
- 分类：饮食运动
- 适用阶段：全周期
- 关键词：熬夜、作息、睡眠、晚睡、夜班
- 核心要点：
  1. 长期熬夜、昼夜节律紊乱（如夜班、频繁倒时差）与月经不规律有关。
  2. 成年人建议每晚睡 7–9 小时。
  3. 中医强调「起居有常」，经期尤其要避免过劳。
- 建议做法：
  1. 每天固定起床时间，周末也尽量不差超过 1 小时。
  2. 睡前 1 小时停用电子屏幕，可以做拉伸或泡脚。
- 需要就医的信号：长期失眠超过 3 个月。
- 证据等级：B
- 来源：T/CACM 1112—2023 第 4.3.2 节；Rosen Vollmar 等 2024 综述

## [KB-05-007] 喝水与体温管理
- 分类：饮食运动
- 适用阶段：全周期
- 关键词：喝水、补水、怕冷、手脚冰凉、保暖
- 核心要点：
  1. 充足饮水有助于缓解经期头痛、便秘和水肿。
  2. 中医认为经期「血得热则行，得寒则凝」，所以要注意保暖；手脚冰凉者多属阳虚或气血不足体质。
- 建议做法：
  1. 每天饮水约 1500–1700 mL，以温水为主。
  2. 腹部、腰部、脚踝保暖；夏天空调温度不要太低。
- 需要就医的信号：长期怕冷伴乏力、体重增加、便秘（排查甲状腺功能减退）。
- 证据等级：B（中医部分 C）
- 来源：《中国居民膳食指南（2022）》；T/CACM 1112—2023
