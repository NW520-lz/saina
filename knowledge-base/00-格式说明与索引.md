# 经期健康知识库 · 格式说明与索引

本知识库供「经期小管家」AI 智能体（女娲 Nuwax）做 RAG 检索使用。
所有条目采用**同一格式**，一个条目 = 一个二级标题，便于平台按标题自动分段。

## 条目格式（每条都必须包含以下字段）

```
## [KB-文件号-序号] 条目标题
- 分类：基础知识 / 阶段护理 / 不适处理 / 就医信号 / 饮食运动 / 中医调养 / 情绪心理 / 备孕避孕
- 适用阶段：行经期 / 卵泡期(经后期) / 排卵期(经间期) / 黄体期(经前期) / 全周期
- 关键词：用顿号分隔，方便检索命中
- 核心要点：
  1. 事实性内容，尽量给出数字范围
- 建议做法：
  1. 用户可以自己执行的具体动作
- 需要就医的信号：出现即建议就医的情况；没有则写「无特殊」
- 证据等级：A（权威指南/系统综述）/ B（临床研究）/ C（专家共识/传统经验，证据有限）
- 来源：机构或文献名称
```

## 阶段命名对照（西医 ↔ 中医）

| App 中显示 | 西医名称 | 中医名称（T/CACM 1112—2023） | 大致时间（以 28 天周期为例） |
|---|---|---|---|
| 月经期 | 月经期 | 行经期 | 第 1–5 天 |
| 卵泡期 | 卵泡期 | 经后期 | 经净 → 排卵前 |
| 排卵期 | 排卵期 | 经间期 | 约第 14 天前后 |
| 黄体期 | 黄体期 | 经前期 | 排卵后 → 下次月经前 |

## 使用原则（智能体必须遵守）

1. 本知识库仅用于**健康科普与生活方式建议**，不能替代医生诊断。
2. 排卵期/易孕期为**根据历史周期推算的估计值**，不能作为避孕依据。
3. 用户描述的情况命中任一「需要就医的信号」时，必须明确、温柔地建议就医。
4. 证据等级为 C 的内容（多为中医传统经验），回答时应使用「可以试试」「有人觉得有帮助」等措辞，不夸大疗效。
