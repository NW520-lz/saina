# 健康知识库构建

产出一组可以直接上传 RAG 平台的 Markdown 文件。一个条目 = 一个二级标题，平台按标题切分后检索命中率高。

## 流程

1. **确定主题清单**：按用户场景拆成 6–10 个文件，例如：基础知识、阶段护理、常见不适、就医信号、饮食运动、中医调养、情绪心理、特殊人群。
2. **检索一手来源**（优先级从高到低）：
   - 西医：ACOG / FIGO / NICE（含 CKS）/ WHO / RCOG / SOGC 指南，Cochrane 与系统综述，NEJM 等原始研究
   - 中医：中华中医药学会团体标准（T/CACM）、国家标准馆、规划教材、名老中医经验文章
   - 营养：中国营养学会 DRIs、《中国居民膳食指南》
   - 搜索方法：exa / WebSearch 用「机构名 + 主题 + guideline」检索，记下具体数字（范围、天数、剂量、比例）
3. **按统一格式写条目**（见下方模板），每条都要有证据等级和来源。
4. **写 00 索引文件**：说明格式、术语对照表（例如西医阶段 ↔ 中医分期）、文件索引，以及智能体必须遵守的使用原则。
5. **自查**：
   - 数字有来源，没有编造的研究
   - 中医/传统经验条目标为 C，措辞是「可以试试」，不说「治疗」
   - 每个可能危险的场景都写了「需要就医的信号」
   - 药物只写类别加「按说明书/遵医嘱」，不写处方剂量方案
6. **配套系统提示词**：写一份提示词，要求智能体优先检索知识库，按证据等级调整措辞，命中就医信号时必须建议就医。

## 条目模板

```markdown
## [KB-文件号-序号] 条目标题
- 分类：
- 适用阶段：
- 关键词：用顿号分隔，覆盖用户的口语说法（如「肚子疼、经痛」）
- 核心要点：
  1. 事实，尽量带数字范围
- 建议做法：
  1. 用户可以自己执行的具体动作
- 需要就医的信号：没有则写「无特殊」
- 证据等级：A（权威指南/系统综述）/ B（临床研究）/ C（专家共识/传统经验）
- 来源：机构或文献名称
```

## 要点

- 关键词要写用户的**口语说法**，这是 RAG 能否命中的关键。
- 「就医信号」放在每条里而不是单独汇总，这样检索到任何一条都能带出安全提醒；另外再单独写一条「紧急情况」总条目。
- 统计类内容（如排卵预测准确率、避孕方法失败率）必须写明局限，避免用户误用。
- 参考实现：`knowledge-base/`（经期健康，56 条，8 个主题）。
